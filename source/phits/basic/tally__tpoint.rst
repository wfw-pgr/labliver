##############################################################
点検出器タリー "t-point" の使い方
##############################################################

=========================================================
t-pointとは
=========================================================

* とある１点の線量は、検出器が有限の体積を持つことから、本来は実現不可能
* 計算を使用して、１点の線量を算出する．

  
=========================================================
注意点
=========================================================

* ver 3.27 において、EGS5と併用ができない． ( protonやneutronの場合のみ )

  - 実際、電子加速器のシミュレーションをやっている人は  :red:`使用できない` 
  - エラーはでないが、十分ではない計算結果がでる（明らかにt-crossと異なる計算結果）

* 使用しない
