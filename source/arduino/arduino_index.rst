=========================================================
arduinoとは
=========================================================

arduino の特徴は下記である ( generated by chatGPT ).

* オープンソース: ハードウェアとソフトウェアがオープンソースで、誰でも利用・改良可能
* プログラミング: 簡単にプログラム可能なマイクロコントローラボード
* 多機能: センサーやアクチュエータと連携して、様々なプロジェクトに対応
* 教育用途: 初心者からプロまで使える教育・プロトタイピングツール
* コミュニティ: 活発なユーザーコミュニティがサポートとリソースを提供
