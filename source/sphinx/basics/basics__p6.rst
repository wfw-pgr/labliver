=========================================================
image ディレクティブ
=========================================================

---------------------------------------------------------
書き方
---------------------------------------------------------

* imageディレクティヴを用いて、図の挿入ができる．

.. code-block::
   
   .. image::  （図のファイル名）
               :scale:  （倍率）       ( e.g. 40 %  etc. )
               :height: （ピクセル数） ( e.g. 100px )
               :width:  （ピクセル数） ( e.g. 100px )
               :align:  （位置）       ( e.g. left, center, etc. )

|

.. note::
   
   * サイズ指定は上記の :blue:`どれかひとつ` を使えば良い．
   +  :red:`width がもっとも直感的でわかりやすい` ． ( 例えば、 :width: 600px などとする )

|
      

---------------------------------------------------------
命令の使用例
---------------------------------------------------------

.. code-block::

   .. image:: images/lena_ja.png
              :width:  300px
              :align:  center

|

---------------------------------------------------------
表示例 (上記、命令)
---------------------------------------------------------

.. image:: images/lena_ja.png
           :width:  300px
           :align:  center

|
