=========================================================
PBSの操作例
=========================================================

---------------------------------------------------------
ジョブ投入 (qsub)
---------------------------------------------------------

::

   qsub pbs.sh

   
---------------------------------------------------------
ジョブ/キューの確認 (qstat)
---------------------------------------------------------

* ジョブの確認は、

::

   qstat


* キューの確認は、

::

   qstat -Q


   
---------------------------------------------------------
ジョブ削除
---------------------------------------------------------

* qstatで投入ジョブのIDを調べて..

::

   qdel "JOBID01"
