git/gitHub とは？
=========================================================

* git はソースコードなどの変更履歴を記録・追跡できる分散型バージョン管理システム(wikipedia).
* gitHubは、コードのバージョン管理にgitを用いたソフトウェア開発プラットフォーム．

.. topic:: git/github (公式サイトより)
   
           "開発者のためのプラットフォーム gitHubは、ユーザのみなさんからヒントを得て作成された開発プラットフォームです．オープンソースプロジェクトやビジネスユースまで、gitHub上にソースコードをホスティングすることで数百万人もの他の開発者と一緒にコードのレビューを行ったり、プロジェクトの管理をしながら、ソフトウェアの開発を行うことができます．"
