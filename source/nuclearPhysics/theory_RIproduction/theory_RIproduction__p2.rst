RI製造量評価の理論式 (2)
##############################################################

=========================================================
放射能時間発展の基本式
=========================================================

ビーム OFF のとき：

.. math::

   \dfrac{dN_P}{dt} &= -\lambda_P N_P \\
   \dfrac{dN_D}{dt} &= +\lambda_P N_P - \lambda_D N_D

ビーム ON のとき：

.. math::

   \dfrac{dN_P}{dt} &= - \lambda_P N_P + Y_N \\
   \dfrac{dN_D}{dt} &= + \lambda_P N_P - \lambda_D N_D

各初期条件に従って解けばよい．



=========================================================
各初期条件の一般解
=========================================================

---------------------------------------------------------
親( :math:`N_P` )の一般解
---------------------------------------------------------

+ ビームOFF：

.. math::

   N_P = N_P(t_0) \, e^{-\lambda_P (t - t_0)}

   
* ビームON：

.. math::

   N_P = N_P(t_0) \, e^{-\lambda_P (t - t_0)} + \dfrac{Y_N}{\lambda_P} \left[ 1 - e^{-\lambda_P (t - t_0)} \right]


---------------------------------------------------------
娘( :math:`N_D` )の一般解
---------------------------------------------------------

+ ビームOFF：

.. math::

   N_D = \left[ N_D(t_0) - \dfrac{ \lambda_P N_P(t_0) }{ \lambda_D - \lambda_P } \right] e^{ - \lambda_D (t - t_0)} + \dfrac{ \lambda_P N_P(t_0) }{ \lambda_D - \lambda_P } e^{ - \lambda_P (t - t_0)}

   
+ ビームON：

.. math::

   N_D = N_D(t_0) \, e^{-\lambda_D (t - t_0)} + \dfrac{\lambda_P N_P(t_0) - Y_N}{\lambda_D - \lambda_P} \left[ e^{-\lambda_P (t - t_0)} - e^{-\lambda_D (t - t_0)} \right] + \dfrac{Y_N}{\lambda_D} \left[ 1 - e^{-\lambda_D (t - t_0)} \right]



|

これらを **適切な初期条件のもと、接続して解けば** 連続的な時間発展がわかる．

|


=========================================================
RIビーム製造時の飽和放射能
=========================================================

* 初期条件 :math:`t=t_0, N_P(t_0)=0` において、十分長い時間 ( :math:`t-t_0 >> \lambda_P^{-1}` ) 経過すれば、放射能は一定の値に飽和する．
* :math:`N_P( t \rightarrow t_\infty )` において、

.. math::

   N_P = \dfrac{Y_N}{\lambda_P}


放射能で、

.. math::

   A_P = \lambda_P \times \dfrac{Y_N}{\lambda_P} = Y_N
