レガシー元祖高機能 エディタ ::  :red:`Emacs` 
=========================================================

* PC普及前の黎明期 ( 1970s ) からある *GNU* 発の :red:`Unix系の代表的エディタ`
* :red:`拡張性が高い` ことが特徴 ( *Emacs* を書くための専用言語 : **Emacs-Lisp** を使って自分なりにアレンジできる )
* エディタ戦争やってた二大巨塔の片割れ．なお現在は、 **レガシー** とか **枯れた** とか **オワコン** が評判 ( オワコン扱いされてから長い、たぶん、一部の信者を除いて見向きもされない )．
